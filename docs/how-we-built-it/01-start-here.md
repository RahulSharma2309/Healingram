# Start here

Imagine you are building a house.

You do **not** ask one person to be the architect, the mason, the inspector, and the owner who says “the kitchen feels wrong” — all in the same breath, all day, with no drawing.

You also do **not** dump every brick in one pile and hope.

Working with Cursor agents is the same:

1. **You** decide what the house is (the product).
2. You write that down in **files**, not only in chat.
3. You give each helper a **job description** (a skill).
4. You ask **one job at a time** (or a planned wave), in a **new chat** when the old one is tired.
5. You **run the house** (the app on localhost) and say pass or fail.

Chat is a workshop table. It gets messy. **Files** are the drawings that survive.

## The only sentence to remember

> Tell the agent **who it is**, **what “done” means**, and **where the truth lives**. Then make it prove the work on a running app.

That is how Healingram went from a React demo to a laptop marketplace with login, catalog, request, confirm, and pay.
