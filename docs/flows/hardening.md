# Flow — Launch hardening (PO view)

Before we call V1 ready to deploy, a stranger can:

- complete the acceptance journeys in spec §21 on desktop and phone
- get emails in a test inbox (Mailpit in Docker) when a request is confirmed or payment is paid
- recover from every empty and error state without a dead end
- use the header, drawers, and sticky buttons without covering the keyboard or losing focus

Production deployment is a separate step after this epic is done.
