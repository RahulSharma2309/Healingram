# Flow — Find My Match

**Who:** a guest who cannot name a need yet.

## Happy path

1. `/find-my-match` — “Find the retreat that fits you. Takes less than a minute.”
2. Four questions. Continue stays off until the current question has an answer. Back keeps answers. Multi-select cards toggle off if clicked again. Time is single-select.
3. See My Matches runs only against live launch retreats.
4. Each card says why it matches. View Retreat may show “Based on your preferences” — never a diagnosis.
5. Opening a retreat does not lose the answers in this visit.

## If we cannot match exactly

Show closest matches by relaxing optional preferences only. Never invent a retreat. Matches stay inside **published** inventory (any state that has it). Always offer Talk to an Expert.

## What we store

Only non-sensitive answer slugs for the session. No medical claims.
