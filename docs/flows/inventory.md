# Flow — Inventory and publication (PO view)

There is one list of retreats. Homepage, menus, results, match, and listing all read it.

A retreat is shown to the public only when it is active, in Karnataka or Kerala, has the required identity fields, and has at least one valid programme.

A need or destination chip is offered only when at least one public retreat sits behind it.

If a price or testimonial is not verified, we omit it or use the agreed neutral phrase. We do not guess.
