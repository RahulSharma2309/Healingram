# Flow — Inventory and publication (PO view)

There is one list of retreats. Homepage, menus, results, match, and listing all read it.

A retreat is shown to the public only when it is **published** (active, required identity fields, at least one valid programme). **State and city do not block publication.** Geography on the site is derived from those published rows.

A need or destination chip is offered only when at least one public retreat sits behind it. States appear as groups; cities expand under the state the guest selected.

If a price or testimonial is not verified, we omit it or use the agreed neutral phrase. We do not guess.
